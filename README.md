# FAIR4LFCS

A lightweight wrapper around FaIR with GMST conditioning and ECS control for climate simulations.

## Requirements

- Python >= 3.11
- numpy
- pandas
- matplotlib
- tqdm
- [fair](https://github.com/OMS-NetZero/FAIR) (v2.x)

Install with:

```bash
pip install numpy pandas matplotlib tqdm fair
```
